# Frequently Asked Questions (FAQ)

Here are straightforward answers to common questions about FB AdBlocker & Clean Feed.

---

### Is this extension safe to use?
**Yes, 100%.**
- It does not have any backend servers.
- It never connects to external websites.
- It does not collect, save, or send any personal data, passwords, or browsing history.
- The entire source code is right here on GitHub for anyone to inspect.

### Will Facebook ban my account for using this?
**No.** The extension runs locally in your browser to adjust how the page looks to you, similar to an ad-blocker or reader mode. It does not automate clicks, send spam, or interact with Facebook servers under your name.

### Why do I need to enable "Developer mode" to install it?
Because this is an independent, community-driven open-source project distributed directly via GitHub rather than the Google Chrome Web Store. "Developer mode" simply allows your browser to run extensions from a local folder on your computer.

### Why do I see a blank gap sometimes?
Facebook occasionally changes how posts are styled. If you notice a gap or placeholder text:
1. Open the extension popup.
2. Ensure **Clean Mode** is turned **ON**.
3. If an ad still appears, refresh the tab (`F5` or `Ctrl+R`).

### How do I report an ad that didn't get blocked?
Because Facebook frequently updates its layout, some ads might slip through. If you find one:
1. Open the **Issues** tab on this GitHub repository.
2. Click **New Issue**.
3. Describe what showed up (a sponsored post, a new Reels tray, etc.) and what language/region you use Facebook in.
4. Our open-source contributors will update the detection rules!
